PROYECTO DE VIDA — DIANA ARANGO

Cómo agregar la fotografía
---------------------------
1. Abre esta carpeta en Visual Studio Code.
2. Entra en la carpeta "assets".
3. Guarda allí tu fotografía con el nombre exacto: foto-diana.jpg
4. La ruta final debe ser: assets/foto-diana.jpg
5. Abre index.html en el navegador o con Live Server.

Recomendación para la foto
--------------------------
Usa una imagen vertical o cuadrada, preferiblemente de frente y con buena luz.
El diseño la recortará automáticamente en forma circular.

Archivos principales
--------------------
- index.html: contenido de la infografía.
- styles.css: colores, distribución y adaptación a celular.
- app.js: marcador de fotografía y botón para volver al inicio.
